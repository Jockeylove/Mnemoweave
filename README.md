**项目简介：以多智能体记忆、遗忘与协作为核心的多剧本 AI 冒险平台。**

本项目是一款正在设计中的多剧本 AI 协作冒险平台。角色各自经历事件、保存记忆，并在有限容量下整理或遗忘旧经历。玩家安排分工、信息交流和记忆保留，帮助团队在遗忘之后继续完成任务。《暴雪山庄的月光石》是首个合作剧本，侦探题材不限定后续内容。

核心体验：**你的队友无法记住所有经历。你要安排谁记住什么、什么时候互相提醒，让他们一起走到结局。**

**当前状态：设计与开发准备阶段。仓库目前包含设计文档，尚无可运行的游戏。**

## 核心体验

- **分头经历**：角色获得不同的信息，玩家组织它们交流与行动。
- **共同记住**：角色提出整理方案；玩家决定保护片段、安排交流或留在有限的公共板中。
- **承担遗忘**：重要信息可能需要队友提醒、重新调查或替代证据恢复，每条路径和代价由剧本预先定义。
- **回看信息流转**：结局复盘谁获得、分享、压缩或遗忘了信息，以及之后的实际行动。导演工具支持从同一节点比较分支。

三名侦探分工为现场勘查、人物访谈和档案核对。角色可以使用同一个模型，但只读取自己获得的材料与实际收到的消息。

合作本中队员共同追求任务胜利，但共同目标不保证判断正确。后续对抗本允许部分角色表面合作、实际追求隐藏目标，通过隐瞒、误导和合法行动干预团队；它们不能修改世界真相或直接删除别人的记忆。这里的“合作”指玩家与 AI 角色合作，不要求多人联网。

## 首案：暴雪山庄的月光石

暴风雪封住山路，山庄展厅中的月光石不见了。展柜没有被破坏，一条门禁记录成为调查的起点。玩家需要查明谁取走了物品、物品在哪里，以及移动是否得到授权。

案件事实、时间线和证据提前编写；AI 根据自己的记忆实时生成解读、交流和调查建议。游戏过程中不会临时创造新凶手或新线索来改变真相。

## 实现原则

1. 案件规则决定世界中发生了什么；模型决定如何解读、交流和建议行动。
2. 角色不能自动获得其他成员的私人记忆；发送编号也不等于发送证据正文。
3. 导演视图与完整日志不自动进入角色输入。
4. 不预设记忆干预一定导致失败，保留团队主动恢复信息的可能。
5. 现场运行与录制回放明确区分，不把预写对话当作实时模型输出。
6. 关键事实的获取、恢复与替代路径在剧本中预先定义；不临时生成线索救场，也不保证每局必胜。
7. 对抗本的玩家视图不暴露全部私有记忆或隐藏目标；完整轨迹只在结局复盘或独立导演工具中查看。
