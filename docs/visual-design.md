## 用途与画面

用于中英文 README 的顶部配图。四位冒险伙伴将不同来源的记忆卡织成共同故事；外围淡去的卡片表现遗忘。织毯中的山庄、飞船和遗迹代表多剧本题材，不改变首案的固定事实。

这是一张概念插画，不是已实现游戏的截图。生成方式为内置 imagegen 工具，背景不透明。

## 最终生成提示词

```text
Use case: illustration-story.

Primary request: make one beautiful, original editorial game illustration that communicates separate character memories, selective forgetting, and collaboration through the metaphor of weaving memories into a shared story.

Inviting, intelligent, slightly dreamlike; suitable for a student research game demo and a professional open-source project cover. Soft warm paper background, restrained deep ink outlines, gentle teal and amber accents, warm illumination around the shared story. Avoid generic AI neon gradients, glowing brains, circuit boards, cyberpunk robot faces, photorealism, UI dashboards, dense labels, excessive bloom, and decorative clutter.
